Run your status page with Docker

One config file. One command.

config.yaml

hosts:
  - name: Google
    url: https://www.google.com
  - name: GitHub API
    url: https://api.github.com
    conditions:
      code: [200]

Docker

docker run -d \
  -p 8822:8822 \
  -v ./config.yaml:/app/config.yaml \
  -v ./data:/app/data \
  exelban/endpoll:latest

Open http://localhost:8822

Deploy EndPoll with Docker Compose

Copy, paste, and you're done.

services:
  endpoll:
    image: exelban/endpoll:latest
    container_name: endpoll
    restart: unless-stopped
    ports:
      - "8822:8822"
    volumes:
      - ./config.yaml:/app/config.yaml
      - ./data:/app/data
    healthcheck:
      test: ["CMD", "wget", "-qO-", "http://localhost:8822/healthz"]
      interval: 10s
      timeout: 10s
      retries: 3

Frequently asked questions

Is EndPoll free and open source?

Yes. EndPoll is released under the MIT license. You can run it on your own infrastructure without an EndPoll account or subscription. You provide the server and any notification services you choose.

What can I monitor?

EndPoll checks websites and APIs over HTTP/HTTPS, MongoDB, Redis, PostgreSQL, MySQL, TCP ports, DNS records, and hosts via ICMP ping. HTTPS checks also track TLS certificate expiry. See the monitoring configuration guide for examples.

Where is monitoring history stored?

History is stored locally in an embedded BoltDB database by default, with a 90-day uptime chart for each host. Mount the data directory when running Docker to keep history across container replacements. In-memory storage is available when persistence is not needed.

What do I need to host EndPoll?

Use a machine with Docker and network access to the services you want to check. Container images support Linux on amd64 and arm64. You can also build the Go application from source. Follow the Docker installation guide to get started.

Can I keep my status page private?

Yes. Configure ui.basicAuth to require a username and password for the dashboard and API. The health check at /healthz stays public. Use HTTPS when accessing an authenticated dashboard over the internet.
